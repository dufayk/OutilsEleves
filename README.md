# OutilsEleves

Outils interactifs pour les élèves de physique-chimie (Terminale spécialité).

- `chiffres-significatifs.html` : remédiation sur les chiffres significatifs (diagnostic, cours, entraînement adaptatif, test final, rapport PDF).

Aucune donnée n'est envoyée : tout fonctionne dans le navigateur de l'élève.
