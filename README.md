# OutilsEleves

Outils interactifs pour les élèves de physique-chimie.

- `remediation/` : **Remédiation Physique Chimie**. L'élève choisit une notion (chiffres significatifs, vecteurs, vecteurs position-vitesse-accélération…) puis suit diagnostic, fiches de cours, entraînement adaptatif, test final et rapport PDF. Voir `remediation/LISEZMOI.md` pour ajouter une notion.
- `chiffres-significatifs.html` : ancienne version (notion unique), conservée pour les liens existants. La progression des élèves est reprise automatiquement par le nouvel outil.

Aucune donnée n'est envoyée : tout fonctionne dans le navigateur de l'élève.
